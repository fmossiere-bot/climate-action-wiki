# infographics.json: spec for the app

This file tells the web app (wiki.the-uptake.com) how to build the
infographics gallery. The app only has to read one JSON file. Everything else
happens in this repo.

## Where to fetch it

```
https://raw.githubusercontent.com/fmossiere-bot/climate-action-wiki/refs/heads/main/wiki/infographics.json
```

It is regenerated by `.github/scripts/build_infographics.py` (GitHub Action
`build-infographics.yml`) on every push that touches `wiki/infographics/`.
Do not edit it by hand.

## Shape

```json
{
  "version": 1,
  "updated": "2026-10-27",
  "note": "Generated from wiki/infographics/ ...",
  "topics": [
    { "id": "materials", "label": "Materials & waste", "icon": "recycling" }
  ],
  "infographics": [
    {
      "id": "patagonia-circular-economy",
      "title": "Patagonia's circular economy: how it keeps gear in use for longer",
      "caption": "Two or three plain sentences explaining the graphic.",
      "figures": ["212,000 products resold through Worn Wear in FY25", "..."],
      "image_url": "https://raw.githubusercontent.com/.../wiki/infographics/images/patagonia-circular-economy.webp",
      "alt": "Screen-reader description of the image.",
      "credit": { "name": "Antonio Vizcaya Abdo", "url": "https://www.linkedin.com/in/antoniovizcaya/" },
      "source_post": "https://www.linkedin.com/feed/update/urn:li:activity:...",
      "data_source": "Patagonia, Work in Progress Report (November 2025)",
      "origin": "external",
      "topic": "materials",
      "tags": ["circularity", "fashion", "company-evaluations"],
      "related": ["What is the Circular Economy", "..."],
      "wiki": "infographics/patagonia-circular-economy.md",
      "created": "2026-10-27"
    }
  ]
}
```

## Fields

| Field | Notes |
|---|---|
| `id` | Unique slug, same as the wiki filename. Use it in URLs. |
| `title` | Tile heading. |
| `caption` | Short text under the image. May be empty. |
| `figures` | Key numbers typed out from the image. Optional to show. |
| `image_url` | Full URL to a `.webp`, at most 1600px wide. |
| `alt` | Use as the `<img alt>`. |
| `credit` | **Always show** the name, linked to `url` when present. |
| `source_post` | Link to the original post ("View on LinkedIn"). May be empty. |
| `data_source` | Where the numbers come from. Show in the full view. |
| `origin` | `external` (someone else's work) or `own` (made by The Uptake). Could drive an "Original" badge. |
| `topic` | One of the `topics` ids. Use for filter chips. |
| `tags` | Page tags without `#`. |
| `related` | Slugs of related wiki pages, same convention as the `related:` frontmatter elsewhere. |
| `wiki` | Path to the full wiki page, relative to `wiki/`. |
| `created` | `YYYY-MM-DD`. The list is already sorted newest first. |

## What the app should do

The gallery is **images only**. The `.md` pages in `wiki/infographics/` exist
to feed this JSON; they are not articles.

- **Hide the `infographics` category everywhere else**: no page in the library
  or home lists, no article view, and no results in site search. Skip any page
  whose path starts with `infographics/` or whose `category` is `infographics`.
- The Companion already ignores them: `build_snippets.py` skips the folder, so
  they are not in `wiki-snippets.json`.
- Gallery: grid of images, newest first, optional filter chips from `topics`.
- Click opens the image large (lightbox), with the credit and a
  "View original post" link to `source_post`. No caption or body text needed.
- Credit must be visible on the tile itself, not only in the large view.
- `caption`, `figures`, `data_source` and `related` are there if wanted later;
  ignoring them is fine.
